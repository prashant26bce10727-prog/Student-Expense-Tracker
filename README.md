# Student Expense Tracker

A simple Python-based application designed to help students record and analyse their daily expenses.

## Features

* Add expenses
* View all expenses
* Search expenses
* Delete expenses
* Calculate total and average spending
* Find highest and lowest expenses
* Category-wise expense analysis

## Technologies Used

* Python
* Object-Oriented Programming
* Lists and Dictionaries
* Functions
* Loops and Conditional Statements
* Exception Handling

## How to Run

Open the project folder in VS Code and run:

```bash
python main.py
```

## Storage

Expenses are temporarily stored using Python data structures. No database or JSON file is used.
